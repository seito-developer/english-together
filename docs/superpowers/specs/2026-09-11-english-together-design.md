# english-together 設計スペック

- 日付：2026-09-11
- ステータス：承認済み

## 1. 背景と目的

英語学習者にとって、AI との対話を 100% 英語で読み書きするのは認知負荷が高く、続きません。しかし、Claude Code などの CLI や IDE での **AI との対話** には、この負荷を下げる仕組みがありません。

english-together は、次の3つを実現する Agent Skill ／ Claude Code プラグインです。

1. AI の応答に、設定した比率で英語を混ぜる
2. ユーザーが日英を混ぜて書いた指示を、正しく解釈する
3. 設定に応じて、ユーザーの英語をさりげなく添削する

名前は、ルー大柴さんの「トゥギャザーしようぜ！」に由来します。

## 2. 要件

| 項目 | 仕様 |
|---|---|
| 配布形態 | Claude Code プラグインと、汎用の Agent Skills（SKILL.md）の両方。1つのリポジトリがマーケットプレイスとプラグインを兼ねる |
| 言語 | 日本語×英語に特化 |
| 比率 | 英語の割合を 0〜100%、10% 刻みで指定する。中途半端な値は近い値に丸める。初期値は 20% |
| 混ぜる単位 | 比率に応じて自動で変える（低い比率では単語・フレーズ単位、高くなるにつれて文単位） |
| 設定方法 | スラッシュコマンド、設定ファイル（永続化）、自然言語での指示 |
| 入力の扱い | 「解釈のみ（off）」と「解釈＋さりげない添削（on）」を切り替える。初期値は on |
| 有効化 | 設定で常時 ON にできる。初期状態は OFF |
| 混ぜない対象 | コード・コマンド・パス・エラー文／成果物（コミットメッセージ、コードコメント、生成したドキュメント、PR 本文）／重要な警告や確認（日本語で書く） |
| ライセンス | MIT |
| ドキュメント | README.md（日本語）、README.en.md（英語）。設計資料は日本語 |

## 3. アーキテクチャ

```
┌───────────────────────── Claude Code ─────────────────────────┐
│ SessionStart hook ──► inject.sh session ──► rules.md + 現在設定  │
│ UserPromptSubmit  ──► inject.sh prompt  ──► 1行リマインダー      │
│ /english-together … ──► SKILL.md ──► config.sh set …            │
└───────────────────────────────┬───────────────────────────────┘
                                │ 読み書き
                    ~/.config/english-together/config
                                │ 読み取り
┌─────────────── 他のエージェント（Codex、Cursor など）───────────┐
│ SKILL.md（発動時に config と rules.md を読む）                   │
│ 常時 ON にしたい場合は AGENTS.md に指示を追記                    │
└───────────────────────────────────────────────────────────────┘
```

- ルールの本体は `skills/english-together/references/rules.md` の1か所だけに置く。フックもスキルもここを読む
- 設定は、どのエージェントからも同じファイルを参照する

採用しなかった案：

- Output Style：比率を変えるたびにスタイルを切り替える必要があり、他のエージェントにも持っていけない
- スキル単体（フックなし）：長い会話や compaction のあとで、比率が崩れやすい

## 4. コンポーネント

### 4.1 設定ファイル

- 置き場所：`~/.config/english-together/config`。環境変数 `ENGLISH_TOGETHER_CONFIG` で上書きできる
- 形式：`key=value` の行（jq などに依存しないため）

```
enabled=false
ratio=20
correction=on
```

- ファイルがない場合や、値が不正な場合は初期値を使う

### 4.2 `skills/english-together/scripts/config.sh`

POSIX sh で書き、外部への依存はない。

| コマンド | 動作 |
|---|---|
| `config.sh show` | 現在の設定を `key=value` 形式で出力する |
| `config.sh get <key>` | 1つの値を出力する |
| `config.sh set ratio <n>` | 0〜100 の整数を 10 の倍数に丸めて保存する（例：35 → 40、34 → 30）。`%` 付きの入力も受け付ける |
| `config.sh set enabled on\|off` | 有効・無効を保存する（`true`／`false` も受け付ける） |
| `config.sh set correction on\|off` | 添削の有無を保存する |

- 不正な入力のときは、stderr にエラーを出して終了コード 1 を返す
- 書き込みは一時ファイルを経由し、途中で失敗してもファイルが壊れないようにする

### 4.3 `skills/english-together/SKILL.md`

- 発動条件：日英ミックスでの対話、英語比率の変更、ON/OFF、添削の切り替えを要求されたとき（「英語30%で話して」のような自然言語も含む）
- 引数：

| 入力 | 動作 |
|---|---|
| （なし） | 現在の設定で ON にする |
| `30` / `30%` | 比率を 30% にして ON にする |
| `on` / `off` | 有効・無効を切り替える |
| `correct on` / `correct off` | 添削の有無を切り替える |
| `status` | 現在の設定を表示する |

- 設定を変えたら、その場で config.sh を実行し、同じ応答から新しい設定を適用する
- `allowed-tools` で config.sh の実行を事前に許可する

### 4.4 `skills/english-together/references/rules.md`

ルールの本体です。モデルが指示に従いやすいよう、英語で書きます。

- 比率の定義：説明文に含まれる意味のまとまりのうち、英語で書くものの割合。適用外の部分は数えない
- 比率ごとの振る舞い（0 / 10〜30 / 40〜60 / 70〜90 / 100）と、各段階の例文
- 混ぜない対象
- 入力の解釈
- 添削の書式：`💡 English tip:` を応答の末尾に1〜2行で添える。明らかに改善できる点がある場合だけ書く

### 4.5 フック

| イベント | matcher | 出力 |
|---|---|---|
| SessionStart | `startup\|resume\|clear\|compact` | ON のとき、rules.md と現在の設定を標準出力に書く |
| UserPromptSubmit | なし | ON のとき、`hookSpecificOutput.additionalContext` に1行のリマインダーを入れる |

- OFF のときは何も出力しない（トークンを消費しない）
- スクリプトの場所は `${CLAUDE_PLUGIN_ROOT}` で参照する

## 5. エラー処理

- 設定ファイルが読めない、または値が不正：初期値にフォールバックする（フックは処理を止めない）
- フックのスクリプトが失敗しても、対話を止めない（常に exit 0）
- config.sh への不正な入力：エラーメッセージを返し、SKILL.md の指示に従ってユーザーに正しい書き方を案内する

## 6. テスト

- `tests/test_config.sh`：丸め、範囲外や不正な値、`%` 付きの入力、ファイルがない場合の初期値
- `tests/test_inject.sh`：OFF のときは何も出力しない、ON のときの出力内容、JSON として正しいか
- `claude plugin validate . --strict`
- 手動シナリオ：比率 0／20／50／100%、適用外の部分、混在した指示の解釈、添削、OFF の永続化、compaction のあとの維持
- 配布の確認：GitHub からマーケットプレイスを追加してインストールできるか

# 追加設計（v0.2.0、2026-09-20）

## 7. 逆方向（en2ja）への対応

`direction` 設定を1つ追加し、`ratio` の意味を「**学習する言語の割合**」に統一しました。

| `direction` | 使う人 | 応答のベース | 混ぜる言語 |
|---|---|---|---|
| `ja2en`（既定） | 英語を学ぶ日本語話者 | 日本語 | 英語 |
| `en2ja` | 日本語を学ぶ英語話者 | 英語 | 日本語 |

`en2ja` では、日本語の文字が最大の壁になるため、比率 30% 以下のあいだは、応答の中で初めて出てくる日本語の語にローマ字と英語の意味を添えます（例：`入力 (nyūryoku — input)`）。40〜60% では一般的でない語だけ、70% 以上では稀な語だけに絞ります。重要な警告は、その人の母語（`en2ja` なら英語）で書きます。

ルールファイルは、方向に依存しない `rules-core.md` と、方向別の `levels-ja2en.md`／`levels-en2ja.md` に分割しました。フックは共通ルールと使用中の方向の段階表だけを注入します。

## 8. 比率の自動調整

`adaptive` 設定（既定 ON）を追加しました。上げる判定と下げる判定で、担当を分けています。

| 方向 | 担当 | 条件 | 動作 |
|---|---|---|---|
| 下げる | モデル | 「日本語で言って」「もう一回」「意味が分からない」など、**明示の言及**があったとき（1メッセージにつき最大1回） | `config.sh adapt down` で 10% 下げ、カウンタを 0 に戻す。その応答から新しい比率を適用し、1行で知らせる |
| 上げる | フック | `SessionStart` の `startup` が、下げる操作のないまま 3 回続いたとき | `config.sh adapt tick` で 10% 上げ、カウンタを 0 に戻す。注入文で「上がった」ことを伝える |

- 語意の質問（「X ってどういう意味？」）は下げる条件に含めません。学習のための質問まで拾うと、比率が下がり続けてしまうためです。
- `resume`／`clear`／`compact` では数えません。セッションの再開や自動要約のたびに上がるのを防ぐためです。
- `adaptive=off` のときは `adapt` を一切実行しません。
- 範囲は 0〜100% で、両端で止まります。

Claude Code 以外のエージェントにはフックがないため、上げる側は機能しません（下げる側と手動での変更は同じように動きます）。

## 9. 設定ファイルの保護

フックの注入文に `config.sh` の**実パス**を含めます。実装の初期版ではプレースホルダしか渡しておらず、パスが分からなかったモデルが設定ファイルを直接書き換え、`direction` などのキーを失う不具合が実機で発生したためです。ルール側にも「設定ファイルを直接編集しない」と明記しています。
